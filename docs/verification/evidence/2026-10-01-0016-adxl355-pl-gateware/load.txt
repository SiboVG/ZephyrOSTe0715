Result: 18 passed, 3 failed (TC-18.4, TC-19.4, TC-19.5). Every transfer about 3 to 10 times slower than in run 6.

Control, same session, not a sensor_bench run (console excerpt): the same image loaded over JTAG the same way but without pp_te0701.bit gave adxl soak 2000 at 8.93 MHz: min/mean/max 96/104/425 us, adxl timing 200 at 8.93 MHz: 202/207/519 us; this load reported L2_CONTROL 0 before start. With pp_te0701.bit: 96/103/426 us. The slowdown does not depend on the bitstream.

Cause: xsdb read ACTLR = 0x00000000 on the running image (SCTLR with I and C set). With ACTLR.SMP clear the Cortex-A9 does not cache Shareable memory. On the SD boot the FSBL and U-Boot are expected to leave ACTLR.SMP set (the Xilinx boot code sets it; not read back on an SD boot here) and do enable the L2 cache (seen as L2_CONTROL 1 on one JTAG load that halted after them); Zephyr's soc_reset_hook sets neither.
