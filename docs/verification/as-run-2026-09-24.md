# As-run record 2026-09-24

This record assesses the bench runs made after three limitations were fixed, and
after a boot defect found during this work was fixed:

- CSP sends no longer block when no node acknowledges (libcsp patch `0002`);
- the CSP router runs above the F Prime tasks;
- the CSP node can be stored in `te0715.txt` on the SD card;
- `boot.scr` starts Zephyr with U-Boot's MMU and caches off.

The raw evidence is in `docs/verification/evidence/2026-09-24-0102/` (full run,
including the new TC-11) and `docs/verification/evidence/2026-09-24-0111-tc12/`
(TC-12). It is not edited; this page only refers to it. The earlier runs are
assessed in the [as-run record of 2026-09-23](as-run-2026-09-23.md).
